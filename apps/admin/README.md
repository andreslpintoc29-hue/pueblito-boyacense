# Panel Interno — Pueblito Boyacense

Este es el **panel interno del proveedor** de la app "Pueblito Boyacense". Es una herramienta privada para administrar contenidos, servicios, eventos, imágenes y la configuración general de la aplicación.

> ⚠️ **Este panel no está destinado al cliente final.** Su uso es exclusivo del proveedor.

## Tecnología

- **Next.js**
- **React**
- **Supabase**

## Cómo ejecutar

```bash
cd apps/admin
npm install
cp .env.example .env.local
npm run dev
```
